## What's in this org

The developer-facing source for Sociahive — SDKs, runnable recipes, and integration scaffolds. SDK packages ship under the [`@sociahive`](https://www.npmjs.com/org/sociahive) scope on npm and as [`sociahive`](https://pypi.org/project/sociahive/) on PyPI.

## Three doors

| If you want to... | Start here |
|---|---|
| Let an AI assistant drive Sociahive on your behalf | [MCP setup guide](https://docs.sociahive.com/setup-guide) |
| Call the REST API or use the official SDKs | [Developer quickstart](https://docs.sociahive.com/developer-quickstart) |
| Wire Sociahive into Zapier, Make, or n8n | [Developer quickstart](https://docs.sociahive.com/developer-quickstart) (native connectors coming) |
